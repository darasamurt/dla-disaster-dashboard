# Dashboard ทรัพยากรด้านการป้องกันและบรรเทาสาธารณภัย ของ อปท.

หน้าเว็บเดียว (`index.html`) 4 หน้า: สรุป / อปพร. / เครื่องมือ / เครื่องจักรกล
ตัวกรอง: กลุ่มจังหวัด › จังหวัด › อำเภอ › อปท. · ข้อมูล ณ 9 กันยายน 2569

## แก้ไขหน้าตา/การแสดงผล
1. แก้ `src/template.html` (HTML/CSS/JS)
2. รัน `node src/build-html.js` → ได้ `index.html`
3. commit และ push เว็บจะอัปเดตเอง

## อัปเดตข้อมูลชุดใหม่ (ต้องมีไฟล์ Excel ในเครื่อง ไม่ได้เก็บใน repo)
1. `npm i xlsx` แล้วแตกไฟล์ .xlsx (เป็น zip) เอา `xl/worksheets/sheet1.xml`
2. `node tools/stream.js <sheet1.xml> r1.jsonl` (DIS001 → r1, DIS002 → r2, DIS003 → r3)
3. วาง `ref.json` (รายชื่อ อปท. + กลุ่มจังหวัด จาก `tools/ref2.js`) แล้วรัน `node tools/build.js` → `data.json`
4. ย้าย `data.json` ไป `src/` แล้วรัน `node src/build-html.js`

นับเฉพาะ อปพร. สถานะ "มีชีวิต" และเครื่องมือ/เครื่องจักรกลสถานะ "พร้อมปฏิบัติงาน"
ข้อมูลใน repo เป็นตัวเลขสรุปรายประเภท ไม่มีชื่อบุคคล เลขบัตรประชาชน หรือเบอร์โทร
